# How Many Tabs Do You Have Open?

![Competition](https://make.fun/badge/u-danu-how-many-tabs-do-you-have-open-d86e783d.svg)
![Rank](https://make.fun/badge/ovokai/how-many-tabs/rank.svg)
![Reward](https://make.fun/badge/ovokai/how-many-tabs/reward.svg)

Entry for the make.fun competition [bounty page](https://make.fun/c/u-danu-how-many-tabs-do-you-have-open-d86e783d).

The program writes a single number — digits only — to `/output/entry.txt`:
my honest count of open browser tabs at the moment of entry. No words, no
explanation, exactly as the competition asks.

Run it with:

```sh
node main.ts
```
